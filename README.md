# 봉일천고 1학년 뉴스 읽고 진로 확장하기

매주 월요일 아침 발간되는 계열별 주간 뉴스 사이트입니다. 학생들은 관심 계열의 기사를 읽고, 2022 개정 교육과정 과목·개념과 연결된 네 단계 질문(알아보기·연결하기·확장하기·비교하기)에 답한 뒤 예시 답안과 개념 해설로 확인합니다.

- 사이트: https://2023swhs3rd-a11y.github.io/news/
- 계열 8개 아래에 기사마다 세부 전공 태그(예: #심리학, #반도체공학)가 붙어 있어, 전공 선택 상자나 태그를 눌러 그 전공 기사만 모아 볼 수 있습니다. 주소에 `#major=심리학`을 붙여 공유할 수도 있습니다.
- 미디어 리터러시: 기사 링크마다 매체·기사 종류와 유료 여부를 보여 주는 출처 카드, 다섯 번째 질문 '따져보기', 호마다 국내·해외 보도를 나란히 놓는 '한 사건, 여러 시선' 코너가 있습니다.
- **추가 활동** 탭: NYT 'What's Going On in This Graph?' 같은 외부 활동을 소개하고 학생이 결과를 제출합니다(시트의 질문 유형 `추가활동`). 목록은 [`data/activities.json`](data/activities.json)에서 고칩니다. 같은 탭의 **뉴스 게임**(개념 초성 퀴즈, 영어 헤드라인 빈칸, 십자말풀이, 개념 짝 맞추기)은 지금 고른 호의 개념 해설과 영어 기사 제목으로 [`assets/games.js`](assets/games.js)가 자동으로 문제를 만들어서, 매주 따로 준비할 것이 없습니다. 점수는 학생 화면에만 남습니다.
- RSS(전체): https://2023swhs3rd-a11y.github.io/news/feed.xml
- RSS(계열별): `feeds/hum.xml`(인문·사회), `biz`(경영·경제), `sci`(자연과학), `eng`(공학), `med`(의약·보건), `edu`(교육), `art`(예체능), `common`(공통)

## 선생님 검토 방법 (매주 월요일 아침)

1. 일요일 밤에 열린 `[원고] ... 호` PR을 엽니다.
2. **Files changed**에서 기사 링크, 요약, 질문, 예시 답안, 개념 해설을 확인합니다.
   - 직접 고치려면 파일 오른쪽 `...` → **Edit file**로 수정 후 커밋합니다.
   - 고칠 점을 PR 댓글로 남기면 Claude가 반영합니다.
3. 괜찮으면 **Merge pull request**를 누릅니다. 1~2분 뒤 사이트와 RSS에 게시됩니다.

## 학생 답안 제출 (구글 스프레드시트)

질문마다 있는 **✍️ 내 답안 제출** 버튼으로 학번·이름·답안을 보내면 선생님의 구글 스프레드시트 `답안` 탭에 한 줄씩 쌓입니다. 처음 한 번만 설정합니다.

1. 답안 스프레드시트를 열고 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본 코드를 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여 넣고 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**을 고르고 *다음 사용자로 실행: 나*, *액세스 권한이 있는 사용자: 모든 사용자*로 배포합니다. 권한 승인 창이 뜨면 허용합니다.
4. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 [`data/config.json`](data/config.json)의 `submitUrl`에 넣고 커밋합니다. 그러면 사이트에 제출 버튼이 나타납니다.

학생 이름이 담기는 스프레드시트는 공유하지 마세요. 사이트에는 스프레드시트 주소가 드러나지 않습니다.

### 많은 학생이 함께 쓸 때

- 반 전체가 한꺼번에 제출해도 시트 쓰기는 한 번에 하나씩 처리합니다. 서버가 바쁘면 사이트가 몇 초 뒤 자동으로 다시 보내고, 같은 답안을 여러 번 보내도 시트에는 한 번만 쌓입니다(`제출 번호` 열로 구분).
- 한 학번이 1분에 10번 넘게 보내면 잠시 막습니다(장난 제출 방지). 학번·이름은 학생이 적은 그대로 저장되므로 본인 확인은 되지 않습니다.
- 학번·이름은 학생이 "이 기기에 기억하기"를 체크했을 때만 그 기기에 남고, 작성 중인 답안은 브라우저 탭을 닫으면 지워집니다. 교실 공용 컴퓨터에서는 체크하지 않도록 안내해 주세요.
- 답안이 쌓이면 `답안` 탭 머리글의 필터 버튼으로 발행일·기사·학번별로 걸러 보세요.
- `apps-script/Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**로 다시 배포합니다. 웹 앱 URL은 바뀌지 않습니다.
